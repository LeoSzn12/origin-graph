## Findings and verified fixes

### ISSUE-001 — Synthetic fixtures leaked into research UI

**Severity:** medium · **Area:** trust and data integrity

The Theory Lab and hypothesis claim selector surfaced `SYNTHETIC` test-only records as user research data. Production-facing queries now exclude synthetic slugs and the fixture adapter. The lab shows an intentional empty state with a clear creation action when no real hypotheses exist.

- Commit: `41d00e0`
- Regression proof: integration coverage asserts that fixture hypotheses and fixture-adapter claims never appear.
- Before: [hypotheses.png](screenshots/hypotheses.png)
- After: [issue-001-after.png](screenshots/issue-001-after.png)

### ISSUE-002 — Map failed when WebGL was unavailable

**Severity:** high · **Area:** reliability and accessibility

MapLibre threw `Failed to initialize WebGL`, leaving a blank research panel and an unhandled rejection. The map now catches initialization failures and renders a polished, keyboard-accessible coordinate schematic with selectable locations and preserved detail behavior.

- Commit: `ab09b4f`
- Regression proof: unit coverage for the fallback projection; browser console verified clean.
- Before: [map.png](screenshots/map.png)
- After: [issue-002-after.png](screenshots/issue-002-after.png)

### ISSUE-003 — Relationship graph was unusable by default

**Severity:** high · **Area:** interaction and visual hierarchy

The graph initially selected an isolated claim, while toolbar controls overlapped at desktop widths and overflowed badly on mobile. Claims with approved connections are now prioritized. The toolbar uses a responsive grid and the initial graph demonstrates a meaningful relationship rather than a single dot.

- Commit: `ebca9df`
- Browser proof: default Timaeus claim displays a connected motif edge; desktop and mobile layouts have no horizontal overflow.
- Before: [graph.png](screenshots/graph.png)
- After: [issue-003-after.png](screenshots/issue-003-after.png), [mobile](screenshots/issue-003-after-mobile.png)

### ISSUE-004 — Sacred Teachers comparison overwhelmed the first view

**Severity:** medium · **Area:** information design

All five figures were selected on entry, clipping the comparison table and creating a dense first experience. The page now starts with three representative selections and displays an explicit selection count, while retaining access to all records.

- Commit: `32e4493`
- Browser proof: the complete three-column comparison is readable without clipping.
- Before: [sacred-teachers.png](screenshots/sacred-teachers.png)
- After: [issue-004-after.png](screenshots/issue-004-after.png)

### ISSUE-005 — Primary navigation clipped on mobile

**Severity:** medium · **Area:** responsive navigation

The desktop labels exceeded the mobile viewport and hid Sources. Responsive labels now preserve the five primary destinations—Explore, Ask, Research, Hypotheses, and Sources—in a single usable row with full accessible names.

- Commit: `c987520`
- Browser proof: all five links fit in the narrow viewport with no horizontal overflow.
- Before: [responsive-home-mobile.png](screenshots/responsive-home-mobile.png)
- After: [issue-005-after.png](screenshots/issue-005-after.png)

### ISSUE-006 — Review loading looked like an empty queue

**Severity:** medium · **Area:** system feedback

The review browser rendered an empty table while data was loading, and a genuinely empty state gave no next action. It now distinguishes loading, fetch failure, true empty, and populated states, with a direct Add source action when appropriate.

- Commit: `a0c4cfa`
- Browser proof: the populated queue loads with explicit state feedback and no console errors.
- Before: [review.png](screenshots/review.png)
- After: [issue-006-after.png](screenshots/issue-006-after.png)

## Behavioral proof

| Journey | Observed behavior |
|---|---|
| Ask an unsupported question | “Did the Battle of Troy really happen?” returns an honest insufficient-evidence state, not unrelated Atlantis or Sahara material; it offers connected-collection search and source contribution actions. |
| Ask a grounded question | Reviewed answers resolve factual claims to evidence locators and expose citations rather than a truth-probability score. |
| Search external collections | The governed provider catalog loads 25 providers; Project Gutenberg live search for “Troy” returned 12 candidate records with source links and a Stage for review action. |
| Explore the graph | A connected reviewed claim renders by default; filters remain usable at desktop and mobile sizes. |
| Explore the map | When WebGL is unavailable, research locations remain selectable through the coordinate fallback instead of a blank screen. |
| Work with hypotheses | Synthetic fixtures are absent; the empty state explains the next action. |
| Review evidence | The review queue differentiates loading, failure, empty, and populated states. |
